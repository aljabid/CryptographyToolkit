## v0.1.0 - Initial Release
- Added classical algorithms:
  - Caesar
  - Hill
  - Playfair
  - Vigenère
- Added modern algorithms:
  - AES
  - RSA
  - ECC
- Added demo scripts in `examples/`
- Added unit tests in `test/`
- Added documentation (`README.md`, `CONTRIBUTING.md`)
- Added project configuration files (`requirements.txt`, `setup.cfg`, `pytest.ini`)
