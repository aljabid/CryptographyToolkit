# CryptographyToolkit

A Python toolkit implementing both classical and modern cryptographic algorithms.  
Includes demos, tests, and modular implementations for educational and practical use.

---

## Features
- Classical algorithms: Caesar, Hill, Playfair, Vigenere
- Modern algorithms: AES, RSA, ECC
- Demo scripts for each algorithm
- Unit tests for validation
- Modular design for easy extension

---
